# Mouse Double-Click Fixer GUI Version

Это графическая версия программы для исправления двойного клика мыши с удобным интерфейсом.

## Особенности GUI версии:

- **Графический интерфейс** с настройкой порога срабатывания в реальном времени
- **Визуальная индикация** работы программы (зеленый/красный индикатор)
- **Подробный лог событий** с цветовым выделением подавленных кликов (красный цвет)
- **Статистика** подавленных и нормальных кликов по типам кнопок
- **Кнопка теста** для демонстрации работы подавления
- **Контроль запуска/остановки** одной кнопкой

## Как проверить, что подавление работает:

1. **Запустите программу** от имени администратора (необходимо для реальной блокировки кликов)
2. **Установите желаемый порог** (по умолчанию 70 мс) с помощью ползунка
3. **Нажмите "Запустить"** - индикатор должен стать зеленым
4. **Для теста:**
   - Нажмите кнопку "Тест подавления" для получения инструкций
   - Или просто быстро дважды кликните мышью где-нибудь на экране
   - Если интервал между кликами меньше установленного порога, вы увидите в логе:
     ```
     [HH:MM:SS] 🔇 ПОДАВЛЕН left клик (интервал: XX.X мс)
     ```
     (сообщение будет красным цветом)
   - Нормальные клики будут отображаться обычным цветом:
     ```
     [HH:MM:SS] Нормальный left клик (интервал: XXX.X мс)
     ```

5. **Следите за статистикой** в нижней части окна - вы увидите количество подавленных кликов
6. **Остановите программу** кнопкой "Остановить" когда закончите

## Требования для реальной блокировки:

- **Запуск от имени администратора** обязателен для реального блокирования кликов мыши
- Без прав администратора программа будет только показывать, какие клики были бы заблокированы
- Для запуска от администратора:
  1. Щелкните правой кнопкой мыши на `mouse_fix_gui.exe`
  2. Выберите "Запуск от имени администратора"
  3. Подтвердите запрос UAC (Контроль учетных записей)

## Настройка порога срабатывания:

- Используйте ползунок "Порог срабатывания (мс)" для настройки чувствительности
- Значение от 10 до 500 миллисекунд
- Меньшее значение = более строгая фильтрация (будет блокировать даже относительно медленные двойные клики)
- Большее значение = более мягкая фильтрация (будет блокировать только очень быстрые двойные клики)
- Рекомендуемое значение для большинства случаев: 50-100 мс

## Файлы в распределении:

- `mouse_fix_gui.exe` - основное приложение с графическим интерфейсом
- `mouse_fix_final.exe` - простая версия без GUI (для тех кто предпочитает минимализм)
- `README.md` - основная документация
- `run_as_admin.bat` - вспомогательный файл для запуска от администратора

## Советы по использованию:

1. Начните с порога 70 мс и при необходимости регулируйте
2. Если вы замечаете, что нормальные двойные клики блокируются - увеличьте порог
3. Если проблема двойного клика не решается - уменьшите порог
4. Программа потребляет минимум системных ресурсов и может работать в фоновом режиме
5. Для временного отключения достаточно нажать кнопку "Остановить"

## Решение проблем:

- **Программа не блокирует клики**: Убедитесь, что вы запустили её от имени администратора
- **Лог не обновляется**: Проверьте, что индикатор активности зеленый (программа запущена)
- **Слишком много ложных срабатываний**: Увеличьте порог срабатывания
- **Двойные клики все еще проходят**: Уменьшите порог срабатывания
- **Программа зависает**: Перезапустите её, возможно потребуется запуск от администратора
